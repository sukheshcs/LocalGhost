# Support

Thank you for using **LocalGhost**! If you're experiencing issues, have questions, or want to suggest new features, we are here to help.

## Reporting Bugs or Issues
If you encounter a bug or something isn't working as expected, please [open a new issue on GitHub](https://github.com/sukheshcs/localghost/issues/new). 

To help us resolve your issue as quickly as possible, please include:
- A brief description of the problem.
- Your macOS version.
- Steps to reproduce the issue.
- Any relevant screenshots or error logs.

## Feature Requests
We'd love to hear your ideas for improving LocalGhost! You can also use the GitHub Issues page to request new features or suggest enhancements. Please add the `enhancement` label to your issue summary if possible.

## General Questions
If you have a general question about how to use the app, feel free to start a discussion or open a question issue on GitHub. 

## Expected Response Time
We review issues regularly and will try to respond to bug reports and critical issues within a few business days.

---
*For the App Store review team: This document serves as the primary support destination for LocalGhost users. All support requests are handled via GitHub Issues.*
